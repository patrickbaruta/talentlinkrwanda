TALENT LINK RWANDA LTD - VERSION 2 NETLIFY PACKAGE

FILES
- index.html: homepage with Mission, Vision and Core Values
- jobs.html: vacancies page with clearly marked sample vacancy templates
- submit-cv.html: candidate CV submission portal
- post-vacancy.html: employer vacancy submission form
- success.html: form confirmation page
- styles.css: shared website styling

DEPLOYMENT
Upload this ZIP through the Netlify project's Deploys area. All files are at the ZIP root.

LOGO
The website works without a logo. To add one, unzip the package, add a PNG named exactly logo.png beside index.html, zip the files again and redeploy.

IMPORTANT OPERATIONAL NOTES
1. Candidate and vacancy forms use Netlify form markup. Test both forms after deployment.
2. File inputs are included for CVs and job descriptions. Confirm file handling, limits and notifications in the Netlify project before public launch.
3. Vacancy form submissions are for review and do not automatically create public job posts. Add verified vacancies manually to jobs.html or connect a content management/backend system later.
4. Replace all sample job cards before advertising live roles.
5. Publish a final privacy notice, candidate consent wording and data-retention policy before collecting CVs.
6. Do not edit HTML using Word, Teams, Loop or Outlook. Use Notepad, Notepad++, Visual Studio Code or GitHub.
